# 🚀 Friendly DevOps Project

 This project is designed for automating deployment processes and ensuring consistent environments across development and production.

## 🌟 What's Inside?

1. **Continuous Integration and Deployment (CI/CD)**: We use GitHub Actions to automatically test and deploy our code.
2. **Containerization**: Docker helps us create consistent environments.
3. **Infrastructure as Code**: Terraform helps us manage our cloud resources with ease.
4. **Local Development**: A handy script to set up your local environment in a jiffy!

## 🚀 Getting Started

1. Clone this repository
2. Run `./setup-local-env.sh` to set up your local environment
3. Start coding!

## 📁 Project Structure

- `.github/workflows/`: Our CI/CD pipeline configuration
- `docker/`: Dockerfile and related configurations
- `terraform/`: Infrastructure as Code files
- `scripts/`: Useful scripts for development and deployment
